# Curso React Avanzado

Repositorio de estudio diseñado para acompañar un curso empresarial de **React Avanzado**. El material está organizado por unidades y separa claramente el contenido teórico, los ejercicios resueltos y el código práctico para clase.

## Estructura del repositorio

```text
unidad-1/
├── contenido/
│   ├── README.md
│   ├── ejercicios-resueltos.md
│   └── ejercicios-practica.md
└── practica/
    ├── README.md
    ├── basico/
    ├── intermedio/
    └── avanzado/
```

## Unidad 1 – Arquitectura y Diseño Profesional en React

**Duración sugerida:** 8 horas

### Objetivos de la unidad
- Comprender cómo estructurar aplicaciones React pensando en escalabilidad empresarial.
- Dominar patrones avanzados de componentes y criterios de diseño profesional.
- Detectar deuda estructural y ejecutar refactorizaciones progresivas con bajo riesgo.
- Practicar con ejercicios resueltos y laboratorios listos para usar en clase.

### Navegación recomendada
1. Lea [`unidad-1/contenido/README.md`](unidad-1/contenido/README.md).
2. Refuerce con [`unidad-1/contenido/ejercicios-resueltos.md`](unidad-1/contenido/ejercicios-resueltos.md).
3. Practique con [`unidad-1/contenido/ejercicios-practica.md`](unidad-1/contenido/ejercicios-practica.md).
4. Ejecute o reutilice los ejemplos de [`unidad-1/practica`](unidad-1/practica).

## Criterios pedagógicos del repositorio
- **Enfoque empresarial:** decisiones justificadas por mantenibilidad, velocidad de entrega y escalabilidad.
- **Aprendizaje por niveles:** básico, intermedio y avanzado.
- **Buenas prácticas accionables:** checklists, anti-patrones, tips y casos de uso.
- **Alineación teoría-práctica:** cada ejercicio resuelto tiene una contraparte en código dentro del módulo.
