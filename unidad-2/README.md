# Unidad 2 – Gestión Avanzada de Estado y Flujo de Datos

## Resultado esperado
Al finalizar esta unidad, el estudiante podrá modelar estado complejo en React, componer contextos con criterio de escalabilidad y tomar decisiones arquitectónicas para estado global y asincronía en productos empresariales.

## Ruta de estudio

### 1. Contenido teórico
- `contenido/README.md`: guía completa de la unidad.
- `contenido/ejercicios-resueltos.md`: ejercicios explicados paso a paso.
- `contenido/ejercicios-practica.md`: ejercicios propuestos para trabajo autónomo o en clase.

### 2. Código de práctica
- `practica/basico/estado-derivado-formulario`: ejemplo alineado con el ejercicio resuelto básico.
- `practica/intermedio/contextos-compuestos`: ejemplo alineado con el ejercicio resuelto intermedio.
- `practica/avanzado/estado-global-estructurado`: ejemplo alineado con el ejercicio resuelto avanzado.

## Sugerencia de facilitación
- **Bloque 1 (2 h):** profundización en hooks y custom hooks profesionales.
- **Bloque 2 (2 h):** manejo de estado complejo y formularios estructurados.
- **Bloque 3 (2 h):** Context API avanzada y composición de contextos.
- **Bloque 4 (2 h):** estado global, asincronía y reto práctico integrador.
