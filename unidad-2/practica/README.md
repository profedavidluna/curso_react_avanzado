# Código de práctica – Unidad 2

Esta carpeta contiene ejercicios resueltos para trabajar estado avanzado, composición de contextos y estado global con asincronía controlada.

## Cómo usar estos ejemplos
1. Cree un proyecto React con su herramienta preferida.
2. Copie el contenido de la carpeta `src` del ejercicio seleccionado.
3. Ejecute el proyecto y utilícelo como base de demostración, análisis o extensión.

## Mapa de ejercicios
- **Básico:** `basico/estado-derivado-formulario`
- **Intermedio:** `intermedio/contextos-compuestos`
- **Avanzado:** `avanzado/estado-global-estructurado`
