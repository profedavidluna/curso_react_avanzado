# Unidad 3 – Optimización, Calidad y Evolución Profesional

## Resultado esperado
Al finalizar esta unidad, el estudiante podrá medir, optimizar y sostener el rendimiento de aplicaciones React, incorporando testing profesional y estrategias de mejora continua sobre código real.

## Ruta de estudio

### 1. Contenido teórico
- `contenido/README.md`: guía completa de la unidad.
- `contenido/ejercicios-resueltos.md`: ejercicios explicados paso a paso.
- `contenido/ejercicios-practica.md`: ejercicios propuestos para trabajo autónomo o en clase.

### 2. Código de práctica
- `practica/basico/optimizacion-render`: ejemplo alineado con el ejercicio resuelto básico.
- `practica/intermedio/code-splitting-progresivo`: ejemplo alineado con el ejercicio resuelto intermedio.
- `practica/avanzado/performance-quality-lab`: ejemplo alineado con el ejercicio resuelto avanzado.

## Sugerencia de facilitación
- **Bloque 1 (2 h):** optimización de render y diagnóstico de renders innecesarios.
- **Bloque 2 (2 h):** code splitting, `React.lazy` y carga diferida con `Suspense`.
- **Bloque 3 (2 h):** virtualización, segmentación de componentes pesados y performance avanzada.
- **Bloque 4 (2 h):** testing profesional, refactorización incremental y reto práctico.
