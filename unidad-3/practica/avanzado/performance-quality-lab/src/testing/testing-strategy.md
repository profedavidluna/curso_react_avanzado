# Estrategia de testing profesional

## Cobertura mínima sugerida
- componente: validar render de estados vacío/cargado,
- hook: validar cálculo de ventana visible,
- comportamiento: validar scroll y actualización de elementos renderizados.

## Secuencia recomendada
1. Escribir prueba de comportamiento principal.
2. Refactorizar por pasos pequeños.
3. Ejecutar pruebas para evitar regresiones.
4. Registrar deuda técnica pendiente y siguiente mejora incremental.
