# Código de práctica – Unidad 3

Esta carpeta contiene ejercicios resueltos para optimización de render, carga diferida, performance avanzada y calidad continua con enfoque profesional.

## Cómo usar estos ejemplos
1. Cree un proyecto React con su herramienta preferida.
2. Copie el contenido de la carpeta `src` del ejercicio seleccionado.
3. Ejecute el proyecto y utilícelo como base de demostración, análisis y mejora incremental.

## Mapa de ejercicios
- **Básico:** `basico/optimizacion-render`
- **Intermedio:** `intermedio/code-splitting-progresivo`
- **Avanzado:** `avanzado/performance-quality-lab`
