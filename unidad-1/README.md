# Unidad 1 – Arquitectura y Diseño Profesional en React

## Resultado esperado
Al finalizar esta unidad, el estudiante podrá diseñar una estructura profesional para aplicaciones React, seleccionar patrones de componentes según el contexto y ejecutar refactorizaciones arquitectónicas con criterio técnico y de negocio.

## Ruta de estudio

### 1. Contenido teórico
- `contenido/README.md`: guía completa de la unidad.
- `contenido/ejercicios-resueltos.md`: ejercicios explicados paso a paso.
- `contenido/ejercicios-practica.md`: ejercicios propuestos para trabajo autónomo o en clase.

### 2. Código de práctica
- `practica/basico/catalogo-cursos`: ejemplo alineado con el ejercicio resuelto básico.
- `practica/intermedio/compound-tabs`: ejemplo alineado con el ejercicio resuelto intermedio.
- `practica/avanzado/soft-629-refactor`: ejemplo alineado con el ejercicio resuelto avanzado.

## Sugerencia de facilitación
- **Bloque 1 (2 h):** organización estructural y diseño por dominios.
- **Bloque 2 (2 h):** patrones avanzados de componentes.
- **Bloque 3 (2 h):** diseño profesional de componentes y API.
- **Bloque 4 (2 h):** refactorización arquitectónica y reto práctico.
