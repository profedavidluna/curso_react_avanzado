# Código de práctica – Unidad 1

Esta carpeta contiene ejercicios resueltos listos para usar como base de laboratorio en clase. Cada ejemplo corresponde a un ejercicio de la guía teórica y está organizado por nivel.

## Cómo usar estos ejemplos
1. Cree un proyecto React con su herramienta preferida.
2. Copie el contenido de la carpeta `src` del ejercicio seleccionado.
3. Ejecute el proyecto y utilícelo como base de demostración, análisis o refactorización guiada.
